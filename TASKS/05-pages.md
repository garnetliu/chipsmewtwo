  **改哪里**：新建 `app/effort-values/page.tsx` 及同目录组件、新建 `lib/stats.ts`

  **达到什么效果**：这个目录当前不存在，从零建。按 prototype 做成**两态**。

  prototype 的选择器是 9 个按钮的网格，真实数据 1025 只放不下 ——
  **改成带搜索的 select**，输入中文名过滤。

  **已选态** —— 左 1/3 参数卡 + 右 2/3 结果卡：

  参数卡：卡头「参数设置」+ 右边「更换 Pokémon」主色链接（点了回未选择态）；
  下面一个当前 Pokémon 的小横条（44×44 色块图 + 中文名 + `No.0001 · 草 / 毒`）；
  再下面「等级（1–100）」标签 + 数字输入框；「性格」标签 + 下拉；
  「努力值总和」+ 右侧 `N / 510`（超 510 时红色）；最后一个整宽「重置全部输入」次要按钮。

  结果卡：卡头「计算结果」+ 右侧两行 11px 灰字说明；
  下面六行，每行 12 栅格：
  2 格项目名（+ 后面小字种族值）、3 格个体值输入框、3 格努力值输入框、
  4 格是进度条 + 17px 主色粗体结果数值（宽度按 `结果 / 300`，HP 那条用绿色其余用主色）。

  **输入校验按 prototype：允许超范围，超了标红报错，不截断。**

  | 情况 | 表现 |
  |---|---|
  | 等级不在 1–100 | 输入框红边红字，下方 11px 红字「等级需在 1–100 之间」 |
  | 个体值不在 0–31 | 同上，「个体值需在 0–31 之间」 |
  | 单项努力值不在 0–252 | 同上，「单项努力值需在 0–252 之间」 |
  | 六项努力值总和 > 510 | 「努力值总和不能超过 510（当前 N）」 |
  | 任一项有错 | 结果卡顶部出现红底条「输入有误，修正标红字段后将自动重新计算」 |

  性格 **25 种全列**（prototype 只列了 7 种，那是演示简化）。
  下拉每项显示形如「固执（攻击↑ 特攻↓）」，无修正的显示「认真（无修正）」。
  系数表是 `lib/stats.ts` 里的代码常量，库里没有这张表。修正是一项 ×1.1、一项 ×0.9。

  能力值公式放 `lib/stats.ts`：

  ```
  HP   = floor((2 × 种族值 + 个体值 + floor(努力值 / 4)) × 等级 / 100) + 等级 + 10
  其余 = floor(floor((2 × 种族值 + 个体值 + floor(努力值 / 4)) × 等级 / 100) + 5) × 性格系数
  ```

  性格系数那一步也要 floor。任一输入变化立即重算，不需要点按钮。

  **怎么算验证通过**：
  1. 访问 `/effort-values`，是未选择态，右侧有「请选择 Pokémon 后开始计算」
  2. 在选择器里输入「妙蛙」能过滤出三只，选妙蛙种子后出六行结果
  3. 点「更换 Pokémon」回到未选择态
  4. `lib/stats.ts` 有 Vitest 单测：50 级、认真性格（无修正）、个体值全 31、努力值全 0
     的妙蛙种子（种族值 45/49/49/65/65/45），六项结果是
     HP 120、攻击 69、防御 69、特攻 85、特防 85、速度 65
  5. 单测再验一组带性格修正的：同样条件但性格是固执（攻击↑ 特攻↓），
     攻击 75、特攻 76，其余四项不变
  6. 等级输入框输 150，输入框标红，下方出现「等级需在 1–100 之间」，
     结果卡顶部出现红底条
  7. 六项努力值各填 252（总和 1512），出现「努力值总和不能超过 510（当前 1512）」
  8. 性格下拉里有 25 项
  9. 改任一输入框的值，不点任何按钮，右侧数值立即变化
  10. 点「重置全部输入」，等级回 50、性格回无修正、个体值回 31、努力值回 0
